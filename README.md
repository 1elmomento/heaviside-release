# Heaviside

A desktop manager for your own Telegram account: your friendships grown into trees from your chat
history, channels read as books, and bulk actions in a click. Everything stays on your computer.

This repository holds the **downloads** and the **website**. Get the latest version from
[Releases](https://github.com/1elmomento/heaviside-release/releases): Windows, macOS (Apple chips)
and Linux (Debian 12+, Ubuntu 24.04+). It's a free beta.

Heaviside is an independent app. It isn't made or endorsed by Telegram.
